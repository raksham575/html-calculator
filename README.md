# HTML Calculator

A simple browser-based calculator developed as a frontend project during my internship training at OneStop.ai.

## Features

- Addition, subtraction, multiplication, and division
- Number input through calculator buttons
- Keyboard input support
- Clear calculator functionality
- CE and Del functionality
- Displays the current input, expression, and calculated result
- Responsive Bootstrap-based layout

## Technologies Used

- **HTML5** – Structure of the calculator interface
- **CSS3** – Custom styling
- **Bootstrap 5.3.8** – Layout, grid system, spacing, and UI styling
- **JavaScript** – Calculator logic and expression evaluation
- **jQuery 3.7.1** – Event handling and DOM manipulation

## How It Works

The calculator accepts input through the on-screen buttons and keyboard. Numbers and arithmetic operators are used to build an expression, which is evaluated when the equals (`=`) button is selected.

The project is implemented entirely on the frontend and does not require a backend or database.
